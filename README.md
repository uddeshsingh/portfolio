# 🚀 Interactive Sci-Fi Portfolio

> A futuristic, immersive portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion**. Features an integrated **playable space shooter game**, a 3D skills visualization, and a responsive sci-fi interface.

## ✨ Features

* **🎮 Interactive Background Game**: A fully playable space shooter game built with the HTML5 Canvas API. Move your mouse to control the ship and click to shoot enemies while browsing.
* *Tracks "Targets Hit" score in real-time.*
* *Particle explosions and dynamic enemy spawning.*


* **🌐 3D Skills Globe**: An interactive, rotating sphere of icons representing technical expertise.
* *Drag to rotate, hover to pause and view details.*
* *Mathematically calculated spherical distribution.*


* **⏳ Journey Timeline**: A vertical, animated timeline showcasing professional experience and education.
* **🧪 Project Showcase**: Interactive cards that reveal project details and tech stacks on hover.
* **🎨 Sci-Fi UI/UX**:
* Glassmorphism effects.
* Neon glow accents (Cyan/Pink theme).
* Smooth scroll animations and typing effects.


* **📱 Fully Responsive**: Optimized for all devices with mobile-friendly navigation.

## 🛠️ Tech Stack

* **Frontend Library**: [React](https://reactjs.org/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Animations**: [Framer Motion](https://www.framer.com/motion/)
* **Graphics**: HTML5 Canvas API (for the Space Background)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Build Tool**: Vite

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

* Node.js (v14 or higher)
* npm or yarn

### Installation

1. **Clone the repository**
```sh
git clone https://github.com/uddeshsingh/portfolio.git
cd portfolio

```


2. **Install dependencies**
```sh
npm install
# or
yarn install

```


3. **Start the development server**
```sh
npm run dev
# or
yarn dev

```


4. Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).

## 🎮 How to Play (Easter Egg)

The background of the Hero section is not just a video—it's a game!

1. **Movement**: Move your cursor to pilot the ship.
2. **Attack**: Click anywhere to fire projectiles.
3. **Objective**: Destroy the incoming pink enemies before they pass you.
4. **Score**: Watch your "TARGETS HIT" count increase in the top right HUD.
